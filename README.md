Primeiro site desenvolvido autoralmente para predição de valores de aluguel no Brasil. Para isso, importei uma base de dados do Zap imóveis (maior parte dos dados entre 2018 e 2020), treinei um modelo de regressão (Catboost) e criei um site no Streamlit com interface e execução do modelo.
